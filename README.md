# Task 20 – Customer Order Count

## Project Overview
This project analyzes customer purchasing behavior by counting the number of unique orders placed by each customer and identifying frequent buyers.

## Objective
- Count orders per customer.
- Identify frequent and repeat customers.
- Understand basic customer purchasing behavior.

## Tools Used
- Microsoft Excel
- SQL

## Dataset
Superstore-style sample dataset.

## Work Completed
- Organized raw customer order data.
- Grouped records using Customer ID.
- Removed duplicate order lines at the order level.
- Counted unique orders using SQL.
- Identified the Top 5 customers.
- Classified customers based on order frequency.

## SQL Concepts Used
- SELECT
- GROUP BY
- COUNT(DISTINCT)
- ORDER BY
- CASE statements
- Common Table Expressions (CTEs)

## Deliverables
- Excel workbook
- SQL queries
- Task report

## Key Learning
Learned how to count unique customer orders, avoid duplicate order counting, and identify frequent buyers using Excel and SQL.

## Conclusion
This task helped improve my understanding of customer analysis, SQL aggregation, and Excel data management.
